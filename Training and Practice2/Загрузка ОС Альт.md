### Загрузка ОС «Альт»: этапы, GRUB2, параметры ядра и практика
#### 1. Этапы загрузки системы
Процесс загрузки ОС «Альт» можно разделить на несколько ключевых этапов.
- **Первый этап** — инициализация BIOS/UEFI. После включения компьютера управление берёт на себя BIOS (или UEFI). В этот момент можно войти в настройки микропрограммы, чтобы выбрать загрузочное устройство — например, включить опцию загрузки с USB-устройства .
- **Второй этап** — работа загрузчика. После инициализации оборудования управление передаётся загрузчику (в ОС «Альт» это GRUB2). Загрузчик выводит на экран меню с доступными вариантами загрузки. Пользователь может выбрать нужный пункт стрелками клавиатуры, нажать Enter для немедленной загрузки или клавишу E для редактирования параметров текущего пункта . Через небольшой таймаут загрузчик автоматически запускает вариант по умолчанию .
- **Третий этап** — загрузка ядра. После выбора пункта меню загрузчик загружает ядро Linux в оперативную память. В процессе загрузки на экране отображаются строки с индикаторами [ OK ] или [FAILED], показывающие статус запуска служб. Нажатие Esc позволяет переключиться на подробный вывод .
- **Четвёртый этап** — монтирование файловых систем. Ядро подключает (монтирует) корневую файловую систему и другие разделы, указанные в конфигурации. При необходимости выполняется проверка файловых систем на наличие ошибок, что может увеличить время загрузки .
- **Пятый этап** — запуск системных служб и вход в систему. После монтирования ФС запускаются системные службы, и система переходит к приглашению входа. В зависимости от конфигурации вход может быть графическим или консольным .

#### 2. Загрузчик GRUB2
GRUB2 (GRand Unified Bootloader version 2) — это основной загрузчик, используемый в ОС «Альт». Он отвечает за выбор операционной системы, загрузку ядра и передачу ему параметров.

Меню загрузки появляется сразу после инициализации оборудования. В нём перечислены доступные варианты загрузки. При первом запуске на компьютере с несколькими ОС некоторые из них могут отсутствовать в меню — они будут добавлены автоматически после перезагрузки .

Горячие клавиши в меню GRUB2:
- **Enter** — загрузить выбранный пункт немедленно
- **E** — открыть редактор параметров текущего пункта загрузки
- **F2** — сменить язык интерфейса загрузчика 
- **F10** — загрузить систему после редактирования параметров 

Структура конфигурации. Основной конфигурационный файл — /boot/grub/grub.cfg. Его не рекомендуется редактировать вручную, так как он генерируется автоматически. Пользовательские настройки вносятся через файл /etc/sysconfig/grub2 (или /etc/default/grub), после чего выполняется команда update-grub для регенерации конфигурации .

Дополнительные пункты меню можно добавить в файл /etc/grub.d/40_custom. Например, для Windows 10, если она не была обнаружена автоматически, можно добавить запись вида:

```bash
menuentry 'Windows 10' {
    search --fs-uuid --no-floppy --set=root <UUID>
    chainloader (${root})/EFI/Microsoft/Boot/bootmgfw.efi
}
```
Где <UUID> — идентификатор загрузочного раздела Windows, который можно узнать командой blkid .

#### 3. Конфигурация GRUB2
Настройка GRUB2 в ОС «Альт» возможна двумя способами: через графический модуль в Центре управления системой (ЦУС) и путём редактирования конфигурационных файлов.

**Графический модуль настройки GRUB2**

Модуль доступен после установки пакета:

```bash
# apt-get install kde5-kcm-grub2
```
Запуск осуществляется из строки поиска («Загрузчик GRUB2») или командой kcmshell5 kcm_grub2. Для сохранения изменений потребуется пароль пользователя, входящего в группу wheel .

Основные вкладки модуля:
- **Основное** — выбор загрузочной конфигурации по умолчанию, настройка времени ожидания, скрытие меню, управление генерацией записей recovery и memtest, проверка наличия других ОС .
- **Внешний вид** — разрешение экрана, цвета меню, выбор фоновой темы .
- **Дополнительно** — параметры ядра Linux, настройки последовательного терминала, установка/восстановление загрузчика .

**Конфигурационный файл ``/etc/sysconfig/grub2``**

Ключевые переменные для ручной настройки :

| Переменная	   | 	Назначение   
| :---     | :---         
GRUB_DEFAULT	  | Пункт загрузки по умолчанию
GRUB_TIMEOUT	  | Время ожидания в меню (в секундах)
GRUB_SAVEDEFAULT	  | Запоминать последний выбранный пункт
GRUB_CMDLINE_LINUX_DEFAULT	  | Параметры ядра по умолчанию
GRUB_DISABLE_RECOVERY	  | Отключить пункты восстановления

После редактирования необходимо выполнить update-grub .

**Grub Customizer**

Альтернативный графический инструмент — Grub Customizer. Позволяет переименовывать, создавать и удалять пункты меню, менять цвета и фоновое изображение. Важно: любая ошибка при редактировании может привести к неспособности системы загрузиться .

#### 4. Конфигурирование парольной защиты GRUB
Защита паролем предотвращает несанкционированное изменение параметров загрузки и прерывание нормальной загрузки системы.

##### Способ 1: grub2-setpassword (простой)
Выполнить от имени root:

```bash
su -
grub2-setpassword
```
Ввести и подтвердить новый пароль. Для применения настроек перезагрузить систему. При попытке редактирования пункта меню (клавиша E) потребуется ввести логин root и пароль .

##### Способ 2: хешированный пароль (более безопасный)
**Сгенерировать хеш пароля:**

```bash
grub-mkpasswd-pbkdf2
```
Дважды ввести пароль и скопировать полученный хеш (начинается с grub.pbkdf2...).

Создать или отредактировать файл /etc/grub.d/07_password:

```bash
#!/bin/bash
cat << EOF
set superusers="username"
password_pbkdf2 username grub.pbkdf2.sha512.10000.9C319...
EOF
```
Заменить username на желаемое имя пользователя, вставить сгенерированный хеш. Сделать файл исполняемым:

```bash
chmod 700 /etc/grub.d/07_password
```
Применить изменения:

```bash
update-grub
```
Отключение пароля для отдельных пунктов

Чтобы не требовать пароль для конкретного пункта (например, для Windows), можно добавить параметр --unrestricted в соответствующую строку menuentry в файле ``/boot/grub/grub.cfg``.

Запрет загрузки в режиме восстановления

Раскомментировать в ``/etc/default/grub``:

```text
GRUB_DISABLE_RECOVERY="true"
```
После чего выполнить update-grub .

#### 5. Особые режимы загрузки
ОС «Альт» поддерживает несколько специальных режимов загрузки, доступных из начального меню загрузчика.
- **LiveCD** — работа операционной системы непосредственно с flash-диска без установки на жёсткий диск. В этом режиме у суперпользователя root пустой пароль .
- **Спасательный LiveCD** — восстановление уже установленной, но повреждённой ОС Linux путём запуска небольшого образа в оперативной памяти. Загрузка завершается запросом логина суперпользователя (root) .
- **Безопасный режим** — позволяет включить или отключить специальные параметры загрузки ядра, предназначенные для безопасного режима. Может быть полезен для запуска системы на старом или нестабильном оборудовании .
- **Тест памяти** — проверка целостности оперативной памяти. Процесс выполняется бесконечно, пока его не остановят; необходимо дождаться окончания хотя бы одного цикла .
- **Оболочка UEFI** — терминал для прошивки, позволяющий запускать EFI-приложения, включая загрузчики UEFI .
- **Режим OEM** — при первой загрузке пользователь попадает в мастер настройки системы (установка пароля root, создание пользователя, настройка сети). В параметрах загрузки прописан systemd.unit=setup.target; после завершения настройки этот параметр удаляется .

#### 6. Управление параметрами ядра Linux
Параметры ядра передаются загрузчиком при загрузке и влияют на поведение системы. Их можно задать двумя способами.
- Разовое изменение при загрузке
- В меню GRUB2 выбрать нужный пункт и нажать E.
- Найти строку, начинающуюся с ``linux /boot/vmlinuz....``
- Дописать в конец строки необходимые параметры, отделив пробелом.
- Нажать F10 для загрузки с новыми параметрами .

**Постоянное изменение**

Добавить параметры в переменную ``GRUB_CMDLINE_LINUX_DEFAULT`` в файле ``/etc/sysconfig/grub2``, затем выполнить ``update-grub``.

**Типичные параметры ядра**

| Параметр	   | 	Действие  
| :---     | :---      
nomodeset	  | Не использовать modeset-драйверы для видеокарты
vga=normal	  | Отключить графический экран загрузки
xdriver=vesa	  | Явно использовать видеодрайвер vesa
acpi=off noapic	  | Отключение ACPI и APIC при проблемах с оборудованием
quiet splash	  | Тихая загрузка с графической заставкой

Эти параметры особенно полезны при возникновении проблем с оборудованием или загрузкой.

#### 7. Управление модулями ядра
**Модули ядра** — это компоненты, расширяющие функциональность ядра (драйверы устройств, файловые системы, сетевые протоколы). В ОС «Альт» управление модулями осуществляется через ЦУС, модуль «Обновление ядра» (раздел «Система»).

Возможности модуля :
- Просмотр списка установленных ядер и загруженного по умолчанию
- Установка, обновление и удаление ядер
- Задание ядра, загружаемого по умолчанию
- Установка и удаление отдельных модулей ядра
- Установленные модули отображаются в главном окне модуля (например, drm, nvidia, virtualbox, r8125 и другие) .
- Обновление ядра через ЦУС:
- Перейти в раздел «Система» → «Обновление ядра».
- Нажать кнопку «Обновить ядро…».
- Дождаться синхронизации базы данных пакетов с репозиторием.
- Если доступно новое ядро — подтвердить обновление кнопкой «Да».
- Новое ядро загрузится только после перезагрузки .
- Установка модулей: если ядро не требует обновления, в окне «Доступные модули» можно отметить необходимые модули и нажать «Установить модули» .

Обновление через командную строку:

```bash
# apt-get update
# update-kernel
# remove-old-kernels
```
Команда update-kernel обновляет и ядро, и модули, если в репозитории появились их новые версии. remove-old-kernels удаляет устаревшие ядра для освобождения места .

#### 8. Практическая работа: Пример
**Цель работы**

Освоить загрузку системы, настройку GRUB2, защиту паролем и управление параметрами ядра.

##### Шаг 1. Загрузка с изменёнными параметрами ядра
- Включить компьютер и дождаться появления меню GRUB2.
- Выбрать пункт загрузки и нажать E.
- В строке linux /boot/vmlinuz... добавить параметр nomodeset (для проверки загрузки на нестабильном видеооборудовании).
- Нажать F10. Система загрузится с указанным параметром.

##### Шаг 2. Настройка таймаута и меню через графический модуль
- Установить модуль: # apt-get install kde5-kcm-grub2
- Запустить: $ kcmshell5 kcm_grub2
- На вкладке «Основное» установить время ожидания 10 секунд и выбрать пункт по умолчанию.
- Сохранить изменения (потребуется пароль wheel-пользователя).

##### Шаг 3. Установка пароля на GRUB2
Сгенерировать хеш: # grub-mkpasswd-pbkdf2

Создать файл /etc/grub.d/07_password с содержимым:

```bash
#!/bin/bash
cat << EOF
set superusers="admin"
password_pbkdf2 admin grub.pbkdf2.sha512.10000.<хеш>
EOF
```
Сделать исполняемым: # chmod 700 /etc/grub.d/07_password

Применить: ``# update-grub``

Перезагрузиться и проверить: при нажатии E в меню GRUB2 должен запрашиваться пароль.

##### Шаг 4. Обновление ядра
Через ЦУС:
- Открыть ЦУС → Система → Обновление ядра.
- Нажать «Обновить ядро…».
- Дождаться проверки и подтвердить обновление.
- Перезагрузиться.

Через командную строку:

```bash
# apt-get update
# update-kernel
# remove-old-kernels

# reboot
```
##### Шаг 5. Проверка
После перезагрузки убедиться, что система загрузилась с новым ядром, а пароль ``GRUB2`` запрашивается при попытке редактирования пункта меню.
