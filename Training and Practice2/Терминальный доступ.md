### Терминальный доступ (RDP, VNC) в ОС «Альт»
#### 1. Протоколы терминального доступа
В ОС «Альт» для организации удалённого доступа к графическому рабочему столу используются два основных протокола:
- **RDP** (Remote Desktop Protocol) — проприетарный протокол Microsoft, обеспечивающий передачу графического интерфейса, звука, буфера обмена и перенаправление устройств. В Linux реализуется через XRDP — свободную реализацию серверной части RDP .
- **VNC** (Virtual Network Computing) — открытый протокол для удалённого управления рабочим столом, основанный на RFB (Remote Framebuffer). В ОС «Альт» реализуется через несколько серверных решений: x11vnc, xorg-extension-vnc, Vino, Krfb .
- **SSH** — протокол защищённого удалённого доступа к командной строке, также может использоваться для туннелирования RDP и VNC-трафика .

#### 2. Клиент протоколов удалённого доступа (RDP, VNC и др.)
##### 2.1 Remmina — универсальный клиент
**Remmina** — основной графический клиент удалённого рабочего стола в ОС «Альт», написанный на GTK+. Поддерживает протоколы RDP, VNC, XDMCP, SSH и другие в едином интерфейсе .

**Установка с плагином RDP:**

```bash
# apt-get install remmina remmina-plugins-rdp
```
Для поддержки VNC и других протоколов можно установить дополнительные плагины:

```bash
# apt-get install remmina-plugins-vnc remmina-plugins-exec
```
**Создание подключения:**

- Запустить Remmina.
- В выпадающем списке выбрать протокол (RDP или VNC).
- Указать IP-адрес и порт сервера.
- Нажать Enter.
- Ввести имя пользователя и пароль .
- Для удобства можно создать профиль подключения, задав параметры соединения заранее .

##### 2.2 xfreerdp — консольный RDP-клиент
Для подключения из командной строки используется xfreerdp:

```bash
# Простое подключение
$ xfreerdp /v:xrdp-server

# С указанием учётных данных
$ xfreerdp /v:xrdp-server /u:<user> /p:<password>

# С пробросом папки
$ xfreerdp /drive:Shared,/home/user/shared /v:192.168.1.100 /u:admin /p:password

# Полноэкранный режим
$ xfreerdp /v:IP_адрес /u:пользователь /p:пароль /size:1920x1080 /f
```
##### 2.3 KRDC — VNC-клиент для KDE
**KRDC** — клиент удалённого рабочего стола для среды KDE, может использоваться совместно с сервером Krfb (Сеть → KRDC) .

#### 3. RDP-сервер на ОС «Альт» (XRDP)
**XRDP** — программа, предоставляющая рабочий стол X и обеспечивающая графический вход с использованием протокола удалённого рабочего стола RDP. Поддерживает удалённое управление графикой, двустороннюю передачу буфера обмена, перенаправление звука и диска. Передача RDP шифруется с использованием TLS по умолчанию .

##### 3.1 Установка XRDP
```bash
# apt-get install xrdp
```
##### 3.2 Включение и запуск служб
```bash
# systemctl enable --now xrdp xrdp-sesman
```
Служба xrdp прослушивает порт 3389/tcp, служба xrdp-sesman — порт 3350/tcp .

##### 3.3 Настройка доступа пользователей
Для доступа к терминальному сеансу пользователь должен быть включён в группу tsusers:

```bash
# gpasswd -a <пользователь> tsusers
```
Для разрешения монтирования папок (проброс диска) пользователь должен быть включён в группу fuse:

```bash
# gpasswd -a <пользователь> fuse
```
##### 3.4 Конфигурация XRDP
Параметры сервера хранятся в файле /etc/xrdp/sesman.ini. Файл содержит разделы: «Globals», «Security», «Sessions», «Session definitions», «Logging», «Chansrv» .

**Некоторые настройки по умолчанию:**

Параметр                 | Значение                   | Описание
------------------- | ------------------------- | -------------------------
ListenPort	 | 3389	 | Порт прослушивания xrdp-sesman
TerminalServerUsers	 | tsusers	 | Группа пользователей для доступа
TerminalServerAdmins	 | tsadmins	 | Группа администраторов
MaxLoginRetry	 | 4	 | Максимум попыток подключения
MaxSessions	 | 50	 | Максимум одновременных подключений
KillDisconnected	 | false	 | Разрыв сеанса при отключении
AllowRootLogin	 | false	 | Разрешить вход под root

##### 3.5 Подключение звука
Для прослушивания звука из терминального сеанса локально необходимо установить пакет:

```bash
# apt-get install pulseaudio-module-xrdp
```
##### 3.6 Подключение USB-устройств
Для перенаправления USB-устройств в сеанс XRDP используется пакет xrdp-usb, состоящий из двух компонентов: серверного (xrdp-usb-session) и клиентского (xrdp-usb-terminal) .

##### 3.7 Настройка межсетевого экрана
При использовании межсетевого экрана необходимо разрешить порт 3389:

```bash
# firewall-cmd --add-port=3389/tcp --permanent
# firewall-cmd --reload
```
#### 4. Варианты организации взаимодействия посредством протокола VNC
ОС «Альт» предлагает несколько вариантов организации VNC-сервера в зависимости от среды рабочего стола и требований.

##### 4.1 x11vnc-service (универсальный)
**x11vnc** — VNC-сервер, работающий с существующим X-сеансом. Может использоваться в качестве службы systemd .

Установка:

```bash
# apt-get install x11vnc-service
```
Запуск службы:

```bash
# chkconfig x11vnc on
# service x11vnc start
```
Сохранение пароля:

```bash
# x11vnc --storepasswd
```
По умолчанию используется порт 5900. Для диагностики можно проверить журнал: **journalctl -u x11vnc**.

##### 4.2 Vino (MATE)
Vino — VNC-сервер для среды MATE, включённый в Альт Рабочая станция. Пакет vino-mate представляет собой форк пакета vino с возвращённым графическим интерфейсом настройки .

Установка:

```bash
# apt-get install vino-mate
```
Настройка: Параметры → Общий доступ к рабочему столу (или vino-preferences) .

**Отключение шифрования (если клиент не поддерживает):**

```bash
$ gsettings set org.gnome.Vino require-encryption false
```
##### 4.3 Krfb (KDE)
**Krfb** — VNC-сервер среды KDE для совместного доступа к рабочему столу. Пакет включён в Альт Рабочая Станция К .

Установка:

```bash
# apt-get install kde5-krfb
```
**Запуск: Сеть → Krfb (Общий рабочий стол) или $ krfb**.

Особенности:
- По умолчанию используется порт 5900.
- Можно разрешить доступ без подтверждения, установив пароль в настройках.
- Пользователь может быть ограничен только наблюдением (без управления мышью и клавиатурой).
- Krfb может использоваться совместно с KRDC .

##### 4.4 xorg-extension-vnc
xorg-extension-vnc — расширение Xorg для VNC. Установка:

```bash
# apt-get install xorg-extension-vnc
# subst 's/^#//' /etc/X11/xorg.conf.d/vnc.conf
# vncpasswd
```
Предупреждение: В 10-й версии дистрибутивов ALT этот метод «убивает» графическую оболочку на локальной машине .

##### 4.5 noVNC (доступ через браузер)
**noVNC** — клиент VNC, использующий HTML5, позволяющий подключаться к удалённому компьютеру без установки клиента — только через браузер .

**Установка:**

bash
# apt-get install novnc
Запуск websockify:

```bash
$ websockify 6080 127.0.0.1:5900 --web /usr/share/novnc
```
Где 6080 — порт noVNC, 127.0.0.1:5900 — адрес VNC-сервера, /usr/share/novnc — каталог с веб-интерфейсом .

#### 5. Практическая работа: Примеры
##### Пример 1. Настройка XRDP-сервера и подключение из Windows

Цель: Организовать терминальный доступ к ОС «Альт» с Windows-клиента.

**На сервере «Альт»:**

```bash
# 1. Установка XRDP
apt-get install xrdp

# 2. Запуск и автозагрузка служб
systemctl enable --now xrdp xrdp-sesman

# 3. Добавление пользователя в группу tsusers
gpasswd -a user tsusers

# 4. (Опционально) Добавление в fuse для проброса папок
gpasswd -a user fuse

# 5. Установка звукового модуля
apt-get install pulseaudio-module-xrdp

# 6. Настройка брандмауэра (при необходимости)
firewall-cmd --add-port=3389/tcp --permanent
firewall-cmd --reload
```
На клиенте Windows:
- Открыть «Подключение к удалённому рабочему столу» (mstsc).
- Ввести IP_адрес_сервера:3389.
- Ввести логин и пароль пользователя «Альт».

**Из Linux через xfreerdp:**

```bash
$ xfreerdp /v:192.168.1.100 /u:user /p:password /size:1920x1080
```
##### Пример 2. Настройка VNC-сервера через x11vnc-service
Цель: Организовать постоянный VNC-доступ к рабочему столу.

```bash
# 1. Установка
apt-get install x11vnc-service

# 2. Включение в автозагрузку
chkconfig x11vnc on

# 3. Запуск службы
service x11vnc start

# 4. Сохранение пароля
x11vnc --storepasswd
# Ввести пароль дважды

# 5. Проверка статуса
systemctl status x11vnc
```
**Подключение: с любого VNC-клиента (Remmina, KRDC, vncviewer) к IP_адрес:5900**.

##### Пример 3. Настройка Vino в MATE
Цель: Быстрый доступ к рабочему столу через встроенный VNC-сервер.

```bash
# 1. Установка
apt-get install vino-mate

# 2. Запуск настроек
vino-preferences
```
В открывшемся окне:
- Включить «Разрешить другим пользователям просматривать ваш рабочий стол».
- Включить «Разрешить другим пользователям управлять вашим рабочим столом».
- Установить пароль.

**Если клиент не поддерживает шифрование:**

```bash
$ gsettings set org.gnome.Vino require-encryption false
```
##### Пример 4. Настройка Krfb в KDE
Цель: Организовать совместный доступ к рабочему столу в KDE.

```bash
# 1. Установка
apt-get install kde5-krfb

# 2. Запуск
$ krfb
```
В окне настройки:
- Установить пароль доступа.
- (Опционально) Отметить «Разрешить доступ без подтверждения».
- Изменить порт (по умолчанию 5900) на вкладке «Сеть».
- Подключение — через KRDC или любой VNC-клиент .

##### Пример 5. Подключение через SSH-туннель (безопасный вариант)
Цель: Зашифровать RDP-трафик через SSH.

```bash
# На клиенте создать туннель
$ ssh -L 3390:localhost:3389 user@server

# В другом терминале подключиться к localhost:3390 через RDP-клиент
$ xfreerdp /v:localhost:3390 /u:user
```
Этот метод рекомендуется для максимальной безопасности при передаче данных через публичные сети .

##### Пример 6. Диагностика проблем с RDP/VNC

Проблема            | Решение
------------------- | -------------------------
«Чёрный экран» при VNC	 | Перезагрузить менеджер дисплея (lightdm, sddm) 
Порт занят	 | Проверить ss -tlnp | grep :3389 или :5900
Не подключается XRDP	 | Проверить статус служб: systemctl status xrdp xrdp-sesman
Пользователь не может войти	 | Убедиться, что он в группе tsusers
Брандмауэр блокирует	 | Открыть порт: firewall-cmd --add-port=3389/tcp
Сеанс разрывается	 | Установить KillDisconnected=true в sesman.ini 

**Просмотр журналов XRDP:**

```bash
journalctl -u xrdp
journalctl -u xrdp-sesman
```
