### Установка приложений и обновление системы（ОС «Альт»）
**Пакеты** — это специальные архивы, содержащие исполняемые и конфигурационные файлы, информацию о зависимостях от других пакетов и список действий, необходимых для установки программ. ОС «Альт» использует формат RPM.

**Репозитории** — это специальные хранилища, содержащие пакеты и их индексы (метаданные). APT работает с любым количеством репозиториев одновременно, формируя единую информационную базу.

#### 1. Работа с пакетами менеджером пакетов (APT)
APT (Advanced Packaging Tool) — основная система управления пакетами в ОС «Альт», включающая утилиту apt-get, которая автоматически определяет зависимости между пакетами и строго следит за их соблюдением.

Основные команды APT

| Операция | Команда |
| :--- | :--- |
Обновление индексов репозиториев	 | apt-get update
Установка пакета	 | apt-get install <имя_пакета>
Удаление пакета	 | apt-get remove <имя_пакета>
Обновление всех пакетов	 | apt-get upgrade
Обновление с изменением зависимостей	 | apt-get dist-upgrade
Поиск пакета	 | apt-cache search <текст>
Просмотр информации о пакете	 | apt-cache show <имя_пакета>
Очистка кэша пакетов	 | apt-get clean

Инструмент aptitude

- **aptitude** — оболочка для APT с псевдографическим интерфейсом и интерфейсом командной строки. Ключевое отличие от apt-get: если установленный как зависимость пакет становится ненужным при удалении основного пакета, aptitude автоматически его удалит
- **aptitude** также поддерживает мощный синтаксис запросов, например, можно «заморозить» все пакеты, собранные конкретным мейнтейнером: ``aptitude hold '~mrider@'``

#### 2. Работа с репозиториями
##### Утилита apt-repo

Для управления репозиториями в ОС «Альт» используется утилита apt-repo:

| Операция | Команда |
| :--- | :--- |
Просмотр активных репозиториев	 | apt-repo
Добавление репозитория	 | apt-repo add <репозиторий>
Удаление репозитория	 | apt-repo rm <репозиторий>
Удаление всех репозиториев	 | apt-repo rm all
Обновление информации	 | apt-repo update

Типичный пример — удалить все источники и добавить стандартный репозиторий **P11**:

```bash
# apt-repo rm all
# apt-repo add p11
```
Добавление репозитория на сменном диске

- Создать точку монтирования: # mkdir /media/ALTlinux
- Смонтировать носитель: # mount /dev/sdXN /media/ALTlinux
- Добавить носитель: # apt-cdrom -m add
- Команду монтирования необходимо выполнять перед каждой командой установки пакетов。

**Ручное редактирование**

Список репозиториев хранится в файлах /etc/apt/sources.list и /etc/apt/sources.list.d/

#### 3. Вспомогательные инструменты
**ALT Package Assistant (apa)**
**apa** — графический инструмент для управления пакетами в ALT Linux, объединяющий функциональность нескольких стандартных утилит в едином интерфейсе. Поддерживает поиск пакетов с нечётким поиском, если пакет не был найден при установке, а также удобную работу с тасками в репозиториях

Установка: apt-get install apa

Обновление ядра
```bash
# apt-get update
# update-kernel          # обновление ядра и модулей
# remove-old-kernels     # удаление старых ядер
```
Обновление ядра через update-kernel также обновляет модули ядра, если в репозитории появились их новые версии。

#### 4. Обновление системы через ЦУС
ЦУС (Центр управления системой) предоставляет модуль «Обновление системы» (пакет alterator-updates) из раздела «Система»。

Режимы обновления

| Режим | Описание |
| :--- | :--- |
Автоматически из Интернет	 | Источник обновлений указывается явно
Управляемое сервером	 | Источник вычисляется автоматически при наличии локального сервера обновлений

Рабочие станции «видят» локальный сервер обновлений при выборе режима «Управляемое сервером», если они находятся в домене, а сервер настроен на публикацию как репозиторий。

**Указание локального источника**

При выборе режима «Автоматически из Интернет» можно указать «Другой адрес» и ввести адрес локального сервера, например: ``http://<ip-сервера>/mirror``

**Сервер обновлений**

Модуль ЦУС «Сервер обновлений» (пакет ``alterator-mirror``) из раздела «Серверы» предназначен для зеркалирования репозиториев. По умолчанию локальное зеркало находится в ``/srv/public/mirror``. Уменьшить размер зеркала можно, исключив из синхронизации исходные коды и отладочную информацию: ``SRPMS и *-debuginfo-*``

#### 5. Единая команда управления пакетами (epm)
**epm** — единая команда управления пакетами, разработанная в компании ``Etersoft``. Назначение — унифицировать управление пакетами в дистрибутивах с разными пакетными менеджерами. Утилита упрощает процедуру управления пакетами и может использоваться в скриптах и установщиках。

Поддерживаемые форматы пакетов: ``rpm, deb, tgz, tbz, tbz2, apk, pkg.gz``

Установка eepm
```bash
# apt-get install eepm
```
Основные команды epm 

epm	Альтернатива в ALT

| Операция | Команда |
| :--- | :--- |
Установка пакета	 | epm install <пакет>	apt-get install <пакет>
Удаление пакета	 | epm remove <пакет>	apt-get remove <пакет>
Поиск пакета	 | epm search <текст>	apt-cache search <текст>
Список установленных	 | epm list	rpm -qa
Удаление «сирот»	 | epm autoremove	—
Обновление системы и ядра	 | epm full-upgrade	apt-get dist-upgrade && update-kernel

epm play — установка сторонних программ
```bash
# epm play <имя_программы>
```
Доступные программы включают: ``anydesk, yandex-browser, yandex-disk, zoom и другие``. Команда требует доступа в Интернет

> Важно: при установке сторонних пакетов через ``epm install`` установочные скрипты из пакета не выполняются (для безопасности). Вернуть стандартное поведение можно флагом ``--scripts``.

Для некоторых сторонних rpm-пакетов доступна перепаковка: ``epm install --repack <имя_пакета>``. Для deb-пакетов ключ --repack применяется автоматически

#### 6. Установка приложений средствами Flatpak
**Flatpak** — система для создания, распространения и запуска изолированных настольных приложений в Linux. Приложения устанавливаются из репозитория ``Flathub``

**Установка поддержки Flathub**

Если при установке дистрибутива не был выбран пункт «Репозиторий Flatpak»:

```bash
# apt-get install flatpak-repo-flathub
```
После установки необходимо перелогиниться.

> Важное примечание
Чтобы пользователи, не входящие в группу ``wheel``, могли устанавливать приложения из ``Flathub``, необходимо разрешить доступ к инструментам монтирования ``FUSE`` для всех:

```bash
# control fusermount public
```
Центр приложений

Для запуска Центра приложений следует щёлкнуть соответствующий значок на панели задач. Информация распределена по трём вкладкам:
- Обзор — доступные приложения, сгруппированные по категориям
- Установлено — установленные приложения
- Обновления — статус обновления ПО
- При установке/удалении программ потребуется ввести пароль пользователя root。

#### 7. Практическая работа: Пример
Цель

Установить стороннее приложение через ``epm play``, обновить систему и установить приложение из ``Flathub``.

Ход работы
##### Шаг 1. Обновление индексов и системы

```bash
# apt-get update
# epm full-upgrade
```
##### Шаг 2. Установка приложения через epm play

Проверить список доступных программ:

```bash
$ epm play
```
Установить, например, Yandex Browser:

```bash
# epm play yandex-browser
```
##### Шаг 3. Установка через Flatpak

Убедиться, что установлен пакет flatpak-repo-flathub, и разрешён доступ к FUSE:

```bash
# apt-get install flatpak-repo-flathub
# control fusermount public
```
Перелогиниться. Открыть Центр приложений с панели задач, найти нужное приложение (например, GIMP) и нажать «Установить». Ввести пароль root.

##### Шаг 4. Проверка

Проверить список установленных пакетов:

```bash
$ epm list | grep -i yandex
$ flatpak list
```
