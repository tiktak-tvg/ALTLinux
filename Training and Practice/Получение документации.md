### Получение документации в Linux
#### 1. Справочная система man (UNIX)
man — это «исконная» и наиболее часто применяемая система документации в UNIX-подобных ОС . Практически каждая команда, системный вызов или конфигурационный файл имеют свою справочную страницу (man-страницу).

##### 1.1. Основы работы с man
```bash
# Просмотр справки по команде
man ls

# Просмотр справки по конфигурационному файлу
man hosts

# Просмотр справки по самой команде man
man man
```
##### 1.2. Разделы man-страниц
Man-страницы организованы в пронумерованные разделы. Понимание разделов важно, так как одна и та же тема может встречаться в нескольких разделах .

Раздел              | 	Содержимое
------------------- | -------------------------
1	 | Пользовательские команды
2	 | Системные вызовы
3  | Библиотечные вызовы
4	 | Устройства
5	 | Форматы файлов
6	 | Игры
7	 | Разное (макросы, соглашения)
8	 | Системные команды администрирования
9	 | Внутренние функции ядра

Порядок поиска разделов по умолчанию: 1 n l 8 3 2 3posix 3pm 3perl 3am 5 4 9 6 7 .

Пример важности разделов: Команда man swapon сначала покажет страницу из раздела 8 (команда управления), а не из раздела 2 (системный вызов). Чтобы получить страницу из конкретного раздела, укажите его явно :

```bash
man 2 swapon   # Системный вызов
man 8 swapon   # Команда администрирования
```
##### 1.3. Структура man-страницы
Большинство man-страниц содержит следующие секции :
- НАЗВАНИЕ (NAME) — наименование команды и краткое описание.
- СИНТАКСИС (SYNOPSIS) — краткое описание синтаксиса вызова.
- ОПИСАНИЕ (DESCRIPTION) — подробное описание назначения.
- ПАРАМЕТРЫ (OPTIONS) — список ключей и их значений.
- ФАЙЛЫ (FILES) — связанные файлы.
- СМОТРИТЕ ТАКЖЕ (SEE ALSO) — ссылки на связанные страницы.
- ПРИМЕРЫ (EXAMPLES) — примеры использования.
- АВТОРЫ (AUTHORS) — информация о разработчиках.

##### 1.4. Навигация внутри man
Man-страницы просматриваются через программу less, поэтому работают все её клавиши :

Клавиша             | 	Действие
------------------- | -------------------------
q	     | Выход
Enter	 | Прокрутка на строку вниз
Space	 | Прокрутка на страницу вниз
b	     | Прокрутка на страницу вверх
/строка	   | Поиск строки
n	     | Следующее совпадение
End	   | Конец страницы

##### 1.5. Поиск в man-страницах
```bash
# Поиск по именам страниц (эквивалент whatis)
man -f passwd
whatis passwd

# Поиск по описаниям (эквивалент apropos)
man -k passwd
apropos "remove a directory"

# Обновление базы данных man
sudo mandb
Разница между whatis и apropos: whatis ищет только по именам страниц (целые слова), а apropos — по ключевым словам в описаниях .
```
#### 2. Справочная система проекта GNU — info
info — это гипертекстовая справочная система, созданная в рамках проекта GNU . Она предоставляет ссылки между разделами, что делает чтение больших документов удобнее, чем в man.

##### 2.1. Основы работы с info
```bash
# Открыть главное меню info
info

# Открыть конкретное руководство
info ls
info coreutils
info emacs
```
##### 2.2. Навигация в info
Info использует иерархическую структуру «узлов» (nodes) :

Команда             | 	Действие
------------------- | -------------------------
n	 | Следующий узел (next-node)
p	 | Предыдущий узел (prev-node)
u	 | Вверх по иерархии (up-node)
l	 | Назад по истории (history-node)
t	 | В начало документа (top-node)
d	 | В главное меню (dir-node)
Space	 | Прокрутка вперёд
q	 | Выход
h	 | Справка по клавишам

##### 2.3. Поиск в info
```bash
# Поиск строки во всех руководствах
info -k "search string"
info --apropos="printf"

# Перейти к конкретному узлу
info emacs -n Files
info '(emacs)Files'
```
##### 2.4. Вывод info в файл
```bash
# Рекурсивно выгрузить всё руководство в текстовый файл
info --subnodes -o emacs.txt emacs
```
#### 3. Дополнительные источники справочной информации
##### 3.1. Каталог /usr/share/doc
Основное место для хранения документации к пакетам — каталог /usr/share/doc . Каждый пакет имеет подкаталог с именем, включающим версию.

```bash
# Документация для пакета foo-1.0-alt1
ls /usr/share/doc/foo-1.0-alt1/

# Типичные файлы в каталоге пакета
README      # Основная информация о программе
FAQ         # Ответы на частые вопросы
TODO        # Планы разработчиков
ChangeLog   # История изменений
```
##### 3.2. HOWTO
HOWTO — это собрание практических рекомендаций по использованию Linux. В ALT Linux они находятся в пакете howto, а русские переводы — в howto-html-ru .

```bash
# Просмотр HOWTO
less /usr/share/doc/HOWTO/Название-HOWTO
```
##### 3.3. Команда --help
Многие команды поддерживают ключ --help, который выводит краткую справку :

```bash
ls --help
cat --help
man --help
```
##### 3.4. Поиск файлов: locate
Если вы знаете имя команды, но не знаете, к какому пакету она относится, используйте locate для поиска всех файлов по имени :

```bash
# Обновить базу данных (от root)
sudo updatedb

# Найти все файлы, содержащие "finger"
locate finger
```

#### 5. Пример практического применения
Задача: Найти информацию о команде ssh и её опциях.

##### Шаг 1. Определить, в каком разделе находится нужная страница
```bash
man -f ssh
```
Вывод:

```text
ssh (1)              - OpenSSH SSH client (remote login program)
ssh_config (5)       - OpenSSH SSH client configuration files
sshd (8)             - OpenSSH SSH daemon
```
##### Шаг 2. Просмотреть man-страницу команды
```bash
man 1 ssh
```
##### Шаг 3. Найти конкретную опцию в man
Внутри man нажмите / и введите -p для поиска опции -p (порт). Нажмите n для перехода к следующему совпадению.

##### Шаг 4. Проверить дополнительную документацию в /usr/share/doc
```bash
ls /usr/share/doc/openssh-client/
```
Вывод:

```text
README.Debian
README.gz
changelog.Debian.gz
copyright
```
##### Шаг 5. Посмотреть краткую справку через --help
```bash
ssh --help
```
##### Шаг 6. Если нужно полное руководство — открыть info
```bash
info ssh
```
##### Шаг 7. Найти связанные команды через apropos
```bash
apropos "remote login"
```
Вывод:

```text
rlogin (1)           - remote login
ssh (1)              - OpenSSH SSH client (remote login program)
telnet (1)           - user interface to the TELNET protocol
```
