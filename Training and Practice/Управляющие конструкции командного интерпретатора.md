### Управляющие конструкции командного интерпретатора Bash
#### 1. Переменные в скриптах на языке командного интерпретатора
Переменная — это именованная область памяти, хранящая значение, которое можно изменять в ходе выполнения сценария.

##### 1.1. Определение и использование
```bash
#!/bin/bash

# Определение переменной (без пробелов вокруг =)
NAME="Иван"
AGE=25
CITY="Москва"

# Использование
echo "Имя: $NAME"
echo "Возраст: $AGE"
echo "Город: $CITY"

# Фигурные скобки для отделения имени от текста
echo "Привет, ${NAME}ов!"
echo "Файл: ${NAME}_file.txt"
```
> Важно: между именем переменной, знаком = и значением не должно быть пробелов. NAME = "Иван" — ошибка.

##### 1.2. Типы переменных
```bash
# Строковые
STR="Hello, World"

# Числовые (в bash все переменные — строки, но могут использоваться в арифметике)
NUM=42
FLOAT=3.14

# Массивы
FRUITS=("apple" "banana" "cherry")
echo "${FRUITS[0]}"      # apple
echo "${FRUITS[@]}"      # все элементы
echo "${#FRUITS[@]}"     # количество элементов

# Ассоциативные массивы (bash 4+)
declare -A USER
USER[name]="Иван"
USER[age]=25
echo "${USER[name]}"
```
##### 1.3. Специальные переменные
Переменная	Описание
| Переменная | Описание |
| :--- | :--- |
``$0``	     | Имя скрипта
``$1–$9``	 | Позиционные параметры
``$#``	 | Количество аргументов
``$@``	 | Все аргументы (как отдельные строки)
``$*``	 | Все аргументы (одна строка)
``$?``	 | Код возврата последней команды
``$$``	 | PID текущего процесса
``$!``	 | PID последнего фонового процесса
``$_``	 | Последний аргумент предыдущей команды
``$LINENO``	 | Номер текущей строки
``$RANDOM``	 | Случайное число
``$SECONDS``	 | Время работы скрипта

$#
Пример:

```bash
#!/bin/bash
echo "Скрипт: $0"
echo "Первый аргумент: $1"
echo "Количество аргументов: $#"
echo "Все аргументы: $@"
echo "PID: $$"
echo "Случайное число: $RANDOM"
```
##### 1.4. Предопределённые переменные окружения
```bash
echo $HOME      # домашний каталог
echo $USER      # имя пользователя
echo $PATH      # пути поиска команд
echo $PWD       # текущий каталог
echo $SHELL     # текущая оболочка
echo $LANG      # язык системы
echo $HOSTNAME  # имя хоста
```
##### 1.5. Экспорт переменных
```bash
# Локальная переменная (доступна только в текущей оболочке)
LOCAL_VAR="local"

# Экспорт (доступна дочерним процессам)
export GLOBAL_VAR="global"

# Экспорт существующей переменной
export LOCAL_VAR
```
##### 1.6. Работа со значениями по умолчанию
```bash
# Значение по умолчанию, если переменная не задана
echo "${NAME:-Гость}"

# Присвоить значение по умолчанию
NAME=${NAME:-Гость}

# Ошибка, если переменная не задана
: ${NAME:?"Переменная NAME не задана"}

# Использовать значение, если переменная задана
echo "${NAME:+Привет, $NAME}"

# Длина строки
echo "${#NAME}"
```
##### 1.7. Арифметические операции
```bash
# Через $(( ))
A=5
B=3
echo $((A + B))    # 8
echo $((A - B))    # 2
echo $((A * B))    # 15
echo $((A / B))    # 1
echo $((A % B))    # 2
echo $((A ** B))   # 125

# Через let
let C=A+B
echo $C

# Инкремент/декремент
((A++))
((B--))

# Через expr (устаревший способ)
expr $A + $B
```
##### 1.8. Командная подстановка
```bash
# Через $()
DATE=$(date +%Y-%m-%d)
FILES=$(ls /etc | wc -l)
echo "Сегодня: $DATE, файлов в /etc: $FILES"

# Через обратные кавычки (устаревший способ)
DATE=`date +%Y-%m-%d`
```
#### 2. Позиционные параметры
Позиционные параметры — это аргументы, переданные скрипту при запуске.

##### 2.1. Базовое использование
```bash
#!/bin/bash
# script.sh arg1 arg2 arg3

echo "Имя скрипта: $0"
echo "Аргумент 1: $1"
echo "Аргумент 2: $2"
echo "Аргумент 3: $3"
echo "Все аргументы: $@"
echo "Количество: $#"
```
Запуск:

```bash
chmod +x script.sh
./script.sh apple banana cherry
```
Вывод:

```text
Имя скрипта: ./script.sh
Аргумент 1: apple
Аргумент 2: banana
Аргумент 3: cherry
Все аргументы: apple banana cherry
Количество: 3
```
##### 2.2. Разница между 
``@ и @и*``
```bash
#!/bin/bash
echo "Через \$@:"
for arg in "$@"; do
    echo "  [$arg]"
done

echo "Через \$*:"
for arg in "$*"; do
    echo "  [$arg]"
done
```
Запуск: ./script.sh "a b" "c d"

Вывод:

```text
Через $@:
  [a b]
  [c d]
Через $*:
  [a b c d]
```
``$@`` — каждый аргумент как отдельная строка.

``$*`` — все аргументы как одна строка.

##### 2.3. Сдвиг позиционных параметров
```bash
#!/bin/bash
echo "Первый: $1"
shift
echo "После shift, первый: $1"
shift 2
echo "После shift 2, первый: $1"
```
Запуск: ./script.sh a b c d

Вывод:

```text
Первый: a
После shift, первый: b
После shift 2, первый: d
```
##### 2.4. Проверка аргументов
```bash
#!/bin/bash

# Проверка количества аргументов
if [ $# -ne 2 ]; then
    echo "Использование: $0 <файл1> <файл2>" >&2
    exit 1
fi

echo "Файл 1: $1"
echo "Файл 2: $2"
```
##### 2.5. Обработка опций (getopts)
```bash
#!/bin/bash

while getopts "hf:o:v" opt; do
    case $opt in
        h) echo "Использование: $0 [-h] [-f file] [-o file] [-v]"; exit 0 ;;
        f) INPUT="$OPTARG" ;;
        o) OUTPUT="$OPTARG" ;;
        v) VERBOSE=1 ;;
        \?) echo "Неверная опция: -$OPTARG" >&2; exit 1 ;;
    esac
done

echo "Входной файл: $INPUT"
echo "Выходной файл: $OUTPUT"
[ -n "$VERBOSE" ] && echo "Режим подробного вывода"
```
Запуск: ./script.sh -f input.txt -o output.txt -v

#### 3. Управляющие конструкции условного выполнения
##### 3.1. Конструкция if-then-else
```bash
if условие; then
    # команды, если условие истинно
elif другое_условие; then
    # команды, если другое условие истинно
else
    # команды, если все условия ложны
fi
```
Пример:

```bash
#!/bin/bash

AGE=$1

if [ -z "$AGE" ]; then
    echo "Ошибка: укажите возраст" >&2
    exit 1
fi

if [ "$AGE" -lt 18 ]; then
    echo "Несовершеннолетний"
elif [ "$AGE" -lt 65 ]; then
    echo "Взрослый"
else
    echo "Пенсионер"
fi
```
##### 3.2. Команда test и [ ]
Операторы сравнения чисел:

Оператор	Значение
-eq	Равно
-ne	Не равно
-lt	Меньше
-le	Меньше или равно
-gt	Больше
-ge	Больше или равно
Операторы сравнения строк:

Оператор	Значение
= или ==	Равно
!=	Не равно
<	Меньше (лексикографически)
>	Больше (лексикографически)
-z	Пустая строка
-n	Непустая строка
Операторы для файлов:

Оператор	Значение
-e	Файл существует
-f	Обычный файл
-d	Каталог
-r	Читаемый
-w	Записываемый
-x	Исполняемый
-s	Непустой
-L	Символическая ссылка
file1 -nt file2	file1 новее file2
file1 -ot file2	file1 старше file2

Примеры:

```bash
# Сравнение чисел
if [ "$A" -gt "$B" ]; then
    echo "$A больше $B"
fi

# Сравнение строк
if [ "$NAME" = "admin" ]; then
    echo "Администратор"
fi

# Проверка файла
if [ -f /etc/passwd ]; then
    echo "Файл существует"
fi

# Проверка каталога
if [ -d /tmp ]; then
    echo "Каталог существует"
fi

# Комбинирование условий
if [ -f "$FILE" ] && [ -r "$FILE" ]; then
    echo "Файл существует и читаем"
fi

if [ "$USER" = "root" ] || [ "$USER" = "admin" ]; then
    echo "Привилегированный пользователь"
fi
```
##### 3.3. Двойные квадратные скобки [[ ]]
Bash-специфичная конструкция, более мощная и безопасная:

```bash
# Регулярные выражения
if [[ "$NAME" =~ ^[A-Z][a-z]+$ ]]; then
    echo "Имя с большой буквы"
fi

# Логические операторы без экранирования
if [[ -f "$FILE" && -r "$FILE" ]]; then
    echo "OK"
fi

# Сравнение с шаблоном
if [[ "$FILE" == *.txt ]]; then
    echo "Текстовый файл"
fi
```
##### 3.4. Конструкция case
```bash
case переменная in
    шаблон1)
        команды
        ;;
    шаблон2|шаблон3)
        команды
        ;;
    *)
        команды по умолчанию
        ;;
esac
```
Пример:

```bash
#!/bin/bash

ACTION=$1

case "$ACTION" in
    start)
        echo "Запуск службы..."
        ;;
    stop)
        echo "Остановка службы..."
        ;;
    restart|reload)
        echo "Перезапуск службы..."
        ;;
    status)
        echo "Проверка статуса..."
        ;;
    *)
        echo "Использование: $0 {start|stop|restart|status}" >&2
        exit 1
        ;;
esac
```
##### 3.5. Логические операторы
Оператор	Значение
&&	И (выполнить, если предыдущая успешна)
||	Или (выполнить, если предыдущая неуспешна)
!	Не (инверсия)

```bash
# Короткая форма if
[ -f "$FILE" ] && echo "Файл есть" || echo "Файла нет"

# Инверсия
if [ ! -f "$FILE" ]; then
    echo "Файл не найден"
fi
```
#### 4. Конструкции циклов
##### 4.1. Цикл for
По списку:

```bash
for fruit in apple banana cherry; do
    echo "Фрукт: $fruit"
done
```
По диапазону:

```bash
# Через { }
for i in {1..5}; do
    echo "Число: $i"
done

# С шагом
for i in {0..10..2}; do
    echo "Чётное: $i"
done

# Через seq
for i in $(seq 1 2 10); do
    echo "Число: $i"
done
```
По результатам команды:

```bash
for file in *.txt; do
    echo "Обработка: $file"
done

for user in $(cut -d: -f1 /etc/passwd); do
    echo "Пользователь: $user"
done
```
C-стиль:

```bash
for ((i=0; i<10; i++)); do
    echo "Итерация $i"
done
```
##### 4.2. Цикл while
```bash
while условие; do
    команды
done
```
Пример:

```bash
#!/bin/bash

COUNT=1
while [ $COUNT -le 5 ]; do
    echo "Счётчик: $COUNT"
    ((COUNT++))
done
```
Чтение файла построчно:

```bash
while IFS= read -r line; do
    echo "Строка: $line"
done < file.txt
```
Бесконечный цикл:

```bash
while true; do
    echo "Работаем..."
    sleep 1
done
```
##### 4.3. Цикл until
Выполняется, пока условие ложно (противоположность while):

```bash
COUNT=1
until [ $COUNT -gt 5 ]; do
    echo "Счётчик: $COUNT"
    ((COUNT++))
done
```
##### 4.4. Управление циклами
Команда	Действие
break	Прервать цикл
continue	Перейти к следующей итерации
break N	Прервать N циклов
continue N	Продолжить внешний цикл

Пример:

```bash
# break
for i in {1..10}; do
    if [ $i -eq 5 ]; then
        break
    fi
    echo "Число: $i"
done
# Выведет: 1 2 3 4

# continue
for i in {1..10}; do
    if [ $((i % 2)) -eq 0 ]; then
        continue
    fi
    echo "Нечётное: $i"
done
# Выведет: 1 3 5 7 9
```
##### 4.5. Вложенные циклы
```bash
for i in {1..3}; do
    for j in {1..3}; do
        echo "$i x $j = $((i * j))"
    done
done
```
#### 5. Пример практического применения
Задача: Скрипт резервного копирования с проверками

Цель: Создать скрипт, который:
- Принимает каталог-источник и каталог-назначение.
- Проверяет аргументы и существование каталогов.
- Создаёт резервную копию с датой в имени.
- Ведёт журнал операций.
- Обрабатывает ошибки.

Скрипт backup.sh:
```bash
#!/bin/bash
# Скрипт резервного копирования
# Использование: ./backup.sh <источник> <назначение> [-v]

set -e  # Выход при любой ошибке

# === Переменные ===
SOURCE=""
DEST=""
VERBOSE=0
LOG_FILE="/var/log/backup.log"
DATE=$(date +%Y%m%d_%H%M%S)
HOSTNAME=$(hostname)

# === Функции ===
usage() {
    echo "Использование: $0 <источник> <назначение> [-v]" >&2
    echo "  -v  подробный вывод" >&2
    exit 1
}

log() {
    local level="$1"
    shift
    local message="$*"
    local timestamp=$(date '+%Y-%m-%d %H:%M:%S')
    echo "[$timestamp] [$level] $message" | tee -a "$LOG_FILE"
}

check_dir() {
    local dir="$1"
    if [ ! -d "$dir" ]; then
        log "ERROR" "Каталог не существует: $dir"
        return 1
    fi
    if [ ! -r "$dir" ]; then
        log "ERROR" "Нет прав на чтение: $dir"
        return 1
    fi
    return 0
}

# === Разбор аргументов ===
if [ $# -lt 2 ]; then
    usage
fi

SOURCE="$1"
DEST="$2"
shift 2

while getopts "v" opt; do
    case $opt in
        v) VERBOSE=1 ;;
        *) usage ;;
    esac
done

# === Проверки ===
log "INFO" "Начало резервного копирования"
log "INFO" "Источник: $SOURCE"
log "INFO" "Назначение: $DEST"

if ! check_dir "$SOURCE"; then
    exit 1
fi

# Создать каталог назначения, если не существует
if [ ! -d "$DEST" ]; then
    log "WARN" "Каталог назначения не существует, создаём: $DEST"
    mkdir -p "$DEST" || {
        log "ERROR" "Не удалось создать каталог: $DEST"
        exit 1
    }
fi

if ! check_dir "$DEST"; then
    exit 1
fi

# Проверка свободного места (минимум 1 ГБ)
FREE_SPACE=$(df -m "$DEST" | awk 'NR==2 {print $4}')
if [ "$FREE_SPACE" -lt 1024 ]; then
    log "ERROR" "Недостаточно места: ${FREE_SPACE}MB (нужно минимум 1024MB)"
    exit 1
fi
log "INFO" "Свободное место: ${FREE_SPACE}MB"

# === Создание архива ===
ARCHIVE_NAME="backup_${HOSTNAME}_${DATE}.tar.gz"
ARCHIVE_PATH="${DEST}/${ARCHIVE_NAME}"

log "INFO" "Создание архива: $ARCHIVE_NAME"

if [ "$VERBOSE" -eq 1 ]; then
    tar -czvf "$ARCHIVE_PATH" -C "$(dirname "$SOURCE")" "$(basename "$SOURCE")" 2>&1 | tee -a "$LOG_FILE"
else
    tar -czf "$ARCHIVE_PATH" -C "$(dirname "$SOURCE")" "$(basename "$SOURCE")" 2>>"$LOG_FILE"
fi

if [ $? -eq 0 ]; then
    SIZE=$(du -h "$ARCHIVE_PATH" | cut -f1)
    log "INFO" "Архив создан успешно: $ARCHIVE_PATH ($SIZE)"
else
    log "ERROR" "Ошибка создания архива"
    exit 1
fi

# === Ротация старых архивов (старше 7 дней) ===
log "INFO" "Удаление архивов старше 7 дней..."
DELETED=0
while IFS= read -r old_archive; do
    if [ -n "$old_archive" ]; then
        rm -f "$old_archive"
        log "INFO" "Удалён: $old_archive"
        ((DELETED++))
    fi
done < <(find "$DEST" -name "backup_*.tar.gz" -mtime +7 -type f)

log "INFO" "Удалено старых архивов: $DELETED"

# === Итог ===
TOTAL_ARCHIVES=$(find "$DEST" -name "backup_*.tar.gz" -type f | wc -l)
log "INFO" "Всего архивов в $DEST: $TOTAL_ARCHIVES"
log "INFO" "Резервное копирование завершено успешно"

exit 0
```
Использование:
```bash
# Сделать исполняемым
chmod +x backup.sh

# Запуск
sudo ./backup.sh /home/user /backup

# С подробным выводом
sudo ./backup.sh /home/user /backup -v

# Просмотр журнала
tail -20 /var/log/backup.log
```

Разбор использованных конструкций:
Конструкция	Где используется
Переменные	SOURCE, DEST, DATE, LOG_FILE
Позиционные параметры	$1, $2, $#
getopts	Разбор опции -v
Функции	usage(), log(), check_dir()
if-then-else	Проверка аргументов, каталогов, места
case	Обработка опций
while	Ротация архивов
for	(не используется, но можно заменить)
$( )	Подстановка команд (date, hostname, df)
$(( ))	Арифметика (((DELETED++)))
&& / ||	Логические операторы
Перенаправление	>>, 2>>, tee -a
Код возврата	$?, exit 0, exit 1
