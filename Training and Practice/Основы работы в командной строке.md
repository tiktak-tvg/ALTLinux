### Основы работы в командной строке
#### 1. Интерфейс командной строки
Командная строка — это интерфейс, в котором пользователь взаимодействует с системой путём ввода текстовых команд. В отличие от графического интерфейса, командная строка предоставляет более широкие возможности управления, автоматизации и диагностики.

Структура приглашения командной строки:

```text
user@hostname:~$
```
Элемент	Значение
Элемент             | Значение
------------------- | -------------------------
``user``	            | Имя текущего пользователя
``hostname``	        | Имя компьютера
``~``	            | Текущий каталог (~ — домашний каталог)
``$``	            | Признак обычного пользователя (# — root)
 | :--- | :---  | 
Примеры приглашений:

```bash
# Обычный пользователь в домашнем каталоге
user@astra:~$

# Root в каталоге /etc
root@astra:/etc#

# Пользователь в каталоге /var/log
user@astra:/var/log$
```
Запуск командной строки:
- Графический терминал: Ctrl+Alt+T (в большинстве сред)
- Виртуальные консоли: Ctrl+Alt+F1 — F6
- Удалённо: ssh user@host

#### 2. Типы команд
Все команды в Linux можно разделить на несколько категорий.

##### 2.1. Внешние команды (исполняемые файлы)
Это программы, расположенные в файловой системе (обычно в /bin, /usr/bin, /sbin, /usr/sbin).

```bash
# Полный путь к команде
which ls
# /usr/bin/ls

# Где находится команда
type ls
# ls is /usr/bin/ls

# Все места, где ищется команда
whereis ls
```
##### 2.2. Встроенные команды оболочки (builtins)
Команды, встроенные в саму оболочку (bash). Они выполняются быстрее внешних и могут изменять состояние оболочки.

```bash
# Список встроенных команд
help

# Справка по конкретной встроенной команде
help cd
help echo
```
Основные встроенные команды:

Команда             | Назначение
------------------- | -------------------------
``cd``	   | Смена каталога
``echo``	 | Вывод текста
``pwd``  	 | Текущий каталог
``export`` | Установка переменной окружения
``alias``	 | Создание псевдонима
``history``	 | История команд
``source или .``	 | Выполнение скрипта в текущей оболочке
``type``	 | Определение типа команды
``set``	   | Управление параметрами оболочки
``unset``	 | Удаление переменной

##### 2.3. Псевдонимы (aliases)
Псевдонимы позволяют создавать сокращения для длинных команд.

```bash
# Создать псевдоним
alias ll='ls -la'
alias ..='cd ..'
alias grep='grep --color=auto'

# Просмотр всех псевдонимов
alias

# Удалить псевдоним
unalias ll

# Постоянные псевдонимы — в ~/.bashrc
echo "alias ll='ls -la'" >> ~/.bashrc
source ~/.bashrc
```
##### 2.4. Функции оболочки
Более мощная альтернатива псевдонимам.

```bash
# Создать функцию
mkcd() {
    mkdir -p "$1" && cd "$1"
}

# Использование
mkcd /tmp/newdir
```
#### 3. Терминалы
Терминал — это программа, эмулирующая текстовый терминал для взаимодействия с оболочкой.

##### 3.1. Виды терминалов

Тип                 | Описание
------------------- | -------------------------
Виртуальные консоли	 | Ctrl+Alt+F1…F6, работают без графики
Графические эмуляторы	 | GNOME Terminal, Konsole, XTerm, Fly-Term
Удалённые	 | SSH, Telnet
Псевдотерминалы (pty)	 | Создаются программами (screen, tmux)

##### 3.2. Мультиплексоры терминала
tmux и screen позволяют создавать несколько сессий в одном терминале и отключаться от них без потери работы.

```bash
# Установка tmux
sudo apt install tmux

# Запуск
tmux

# Горячие клавиши (префикс Ctrl+b)
# Ctrl+b c — создать окно
# Ctrl+b n — следующее окно
# Ctrl+b p — предыдущее окно
# Ctrl+b d — отключиться
# Ctrl+b % — разделить вертикально
# Ctrl+b " — разделить горизонтально

# Вернуться к сессии
tmux attach
```
##### 3.3. Полезные команды терминала
```bash
# Очистить экран
clear
# или Ctrl+L

# Информация о терминале
tty
echo $TERM

# Размер терминала
stty size

# Список открытых терминалов
who
w
```

#### 5. История команд
История команд сохраняется в файле ~/.bash_history и доступна через команду history.

##### 5.1. Работа с историей
```bash
# Просмотр истории
history

# Последние 10 команд
history 10

# Поиск по истории
history | grep ssh

# Выполнить команду по номеру
!123

# Выполнить последнюю команду
!!

# Выполнить последнюю команду, начинающуюся с ssh
!ssh

# Очистить историю
history -c

# Удалить конкретную запись
history -d 123
```
##### 5.2. Горячие клавиши истории

Клавиша             | Действие
------------------- | -------------------------
``↑ / ↓``   | Перемещение по истории
``Ctrl+R``	 | Поиск по истории (обратный)
``Ctrl+G``	 | Выход из поиска
``Ctrl+P``	 | Предыдущая команда
``Ctrl+N``	 | Следующая команда
``!!``	     | Последняя команда
``!$``	     | Последний аргумент предыдущей команды

##### 5.3. Настройка истории
В файле ~/.bashrc:

```bash
# Размер истории в памяти
HISTSIZE=10000

# Размер файла истории
HISTFILESIZE=20000

# Игнорировать дубликаты
HISTCONTROL=ignoredups

# Игнорировать команды, начинающиеся с пробела
HISTCONTROL=ignoreboth

# Добавлять время выполнения
HISTTIMEFORMAT="%Y-%m-%d %H:%M:%S "

# Не сохранять определённые команды
HISTIGNORE="ls:cd:pwd:exit:history"
```
##### 5.4. Поиск и повторное использование
```bash
# Поиск команд, содержащих "grep"
history | grep grep

# Выполнить команду из истории с заменой
^old^new^

# Пример: была команда "cat file1.txt"
# ^file1^file2^ выполнит "cat file2.txt"
```
#### 6. Перенаправление консольного ввода-вывода
В Linux каждый процесс имеет три стандартных потока:

Поток               | Дескриптор                | Назначение
------------------- | ------------------------- | -------------------------
stdin 	 | 0	 | Стандартный ввод (клавиатура)
stdout	 | 1	 | Стандартный вывод (терминал)
stderr	 | 2	 | Стандартный вывод ошибок (терминал)

##### 6.1. Перенаправление вывода
```bash
# Перезаписать файл
command > file.txt
ls -la > listing.txt

# Дописать в конец файла
command >> file.txt
echo "new line" >> file.txt

# Перенаправить stderr
command 2> errors.txt
ls /nonexistent 2> errors.txt

# Перенаправить stdout и stderr в один файл
command > all.txt 2>&1
command &> all.txt

# Перенаправить stderr в stdout
command 2>&1

# Отбросить вывод
command > /dev/null
command 2> /dev/null
command &> /dev/null
```
##### 6.2. Перенаправление ввода
```bash
# Читать из файла
command < file.txt
sort < unsorted.txt

# Здесь-документ (heredoc)
cat << EOF
Строка 1
Строка 2
EOF

# Здесь-строка (herestring)
grep "pattern" <<< "some text"
```
##### 6.3. Конвейеры (pipes)
Конвейер | передаёт stdout одной команды на stdin другой.

```bash
# Простой конвейер
ls -la | grep ".txt"

# Несколько команд
cat file.txt | sort | uniq | wc -l

# Подсчёт процессов
ps aux | grep nginx | wc -l

# Топ-10 процессов по памяти
ps aux | sort -k4 -rn | head -10

# Поиск в истории
history | grep ssh | tail -5

# Комбинирование с перенаправлением
cat file.txt | sort > sorted.txt
```
##### 6.4. Команда tee
tee записывает вывод одновременно в файл и на экран.

```bash
# Вывод на экран и в файл
ls -la | tee listing.txt

# Дозапись в файл
ls -la | tee -a listing.txt

# С sudo
echo "content" | sudo tee /etc/config.conf

# Игнорировать прерывания
command | tee -i output.txt
```
##### 6.5. Практические примеры
```bash
# Сохранить список установленных пакетов
dpkg -l > packages.txt

# Найти ошибки в логе
grep -i error /var/log/syslog > errors.txt

# Подсчитать количество строк в файлах
wc -l *.txt > counts.txt

# Извлечь IP-адреса из лога
grep -oE "[0-9]+\.[0-9]+\.[0-9]+\.[0-9]+" access.log | sort | uniq -c | sort -rn

# Найти топ-10 самых больших файлов
du -ah /var | sort -rh | head -10
```
#### 7. Специальные символы командного интерпретатора
##### 7.1. Подстановочные знаки (wildcards)

Символ              | Значение                  | Пример
------------------- | ------------------------- | -------------------------
``*``	 | Любое количество символов (включая ноль)	 | ``ls *.txt``
``?``	 | Один любой символ	 | ``ls file?.txt``
``[abc]``	 | Один из символов	 | ``ls file[123].txt``
``[a-z]`` | Диапазон	 | ``ls file[a-z].txt``
``[!abc]``	 | Кроме указанных	 | ``ls file[!0-9].txt``
``{a,b,c}``	 | Одно из перечисленных	 | ``ls file.{txt,md}``
``{1..5}``	 | Диапазон	 | ``echo file{1..5}.txt``

Примеры:

```bash
# Все .txt файлы
ls *.txt

# Файлы с одним символом в имени
ls ?.txt

# Файлы file1.txt, file2.txt, file3.txt
ls file[1-3].txt

# Создать несколько каталогов
mkdir -p project/{src,doc,test}

# Создать файлы
touch log_{2024..2026}.txt
```
##### 7.2. Кавычки

Тип                 | Описание                  | Пример
------------------- | ------------------------- | -------------------------
``'...'`` | Строгая: всё буквально	echo  | ``'Hello $USER' → Hello $USER``
``"..."``	 | Мягкая: переменные и команды раскрываются | ``echo "Hello $USER" → Hello user``
`` `...` ``	 | Устаревшая подстановка команды	 | ``echo `date` ``
`` $(...) ``	 | Современная подстановка команды	 | ``echo $(date)``

Примеры:

```bash
# Строгая кавычка — переменная не раскрывается
echo 'Текущий пользователь: $USER'
# Текущий пользователь: $USER

# Мягкая кавычка — переменная раскрывается
echo "Текущий пользователь: $USER"
# Текущий пользователь: user

# Подстановка команды
echo "Сегодня: $(date +%Y-%m-%d)"
# Сегодня: 2026-09-22

# Вложенные кавычки
echo "Файл: '$(basename /etc/passwd)'"
# Файл: 'passwd'
```
##### 7.3. Экранирование
```bash
# Экранирование специальных символов
echo "Стоимость: \$100"
# Стоимость: $100

# Пробел в имени файла
touch "my file.txt"
touch my\ file.txt

# Специальные символы
echo "Символ: \*"
# Символ: *
```
##### 7.4. Переменные
```bash
# Определение переменной
NAME="Иван"
AGE=25

# Использование
echo "Имя: $NAME, Возраст: $AGE"
echo "Имя: ${NAME}ов"

# Экспорт в дочерние процессы
export NAME

# Предопределённые переменные
echo $HOME      # домашний каталог
echo $USER      # имя пользователя
echo $PATH      # пути поиска команд
echo $PWD       # текущий каталог
echo $SHELL     # текущая оболочка
echo $?         # код возврата последней команды
echo $$         # PID текущей оболочки
```
##### 7.5. Логические операторы

Оператор            | Значение                  | Пример
------------------- | ------------------------- | -------------------------
`` ;	`` | Последовательное выполнение	 | ``cd /tmp; ls``
``&&``	 | Выполнить, если предыдущая успешна	 | ``cd /tmp && ls``
 II	 | Выполнить, если предыдущая неуспешна	 | cd /tmp II echo "Ошибка"
`` &	`` | Запуск в фоне	 | ``sleep 10 &``

Примеры:

```bash
# Последовательное выполнение
mkdir test; cd test; touch file.txt

# Условное выполнение
cd /etc && ls -la

# Проверка с fallback
ping -c 1 8.8.8.8 || echo "Нет соединения"

# Комбинация
test -f /etc/passwd && echo "Файл есть" || echo "Файла нет"

# Запуск в фоне
long_command &
```
##### 7.6. Группировка команд
```bash
# Группировка в текущей оболочке
{ echo "Строка 1"; echo "Строка 2"; } > file.txt

# Группировка в подоболочке
( cd /tmp && ls ) > listing.txt

# Комбинация
( echo "Начало"; date; echo "Конец" ) | tee log.txt
```
#### 8. Объединение выполнения команд
##### 8.1. Последовательное выполнение
```bash
# Точка с запятой — выполнить всё независимо от результата
command1; command2; command3

# Пример
mkdir dir1; cd dir1; touch file.txt; ls -la
```
##### 8.2. Условное выполнение
```bash
# && — выполнить, если предыдущая успешна (код возврата 0)
command1 && command2

# Пример
apt update && apt upgrade

# || — выполнить, если предыдущая неуспешна (код возврата ≠ 0)
command1 || command2

# Пример
ping -c 1 8.8.8.8 || echo "Сеть недоступна"

# Комбинация
command1 && command2 || command3
```
##### 8.3. Фоновое выполнение
```bash
# Запуск в фоне
command &

# Несколько команд в фоне
(command1; command2) &

# Просмотр фоновых задач
jobs

# Перевести в фон
Ctrl+Z
bg

# Вернуть в foreground
fg
fg %1

# Убить фоновую задачу
kill %1
```
##### 8.4. nohup и disown
```bash
# Запуск с игнорированием SIGHUP
nohup long_command &

# Перенаправление вывода
nohup long_command > output.log 2>&1 &

# Отсоединить от оболочки
disown
disown -h %1
```
##### 8.5. Практические примеры объединения
```bash
# Обновление системы с проверкой
sudo apt update && sudo apt upgrade -y

# Создание резервной копии с проверкой
tar -czf backup.tar.gz /home/user && echo "Бэкап создан" || echo "Ошибка"

# Проверка и создание каталога
[ -d /backup ] || mkdir /backup

# Цепочка проверок
test -f /etc/passwd && test -r /etc/passwd && echo "Читаем" || echo "Нет доступа"

# Мониторинг с записью
while true; do date >> monitor.log; free -h >> monitor.log; sleep 60; done &

# Комплексный пример
( cd /var/log && tar -czf /backup/logs_$(date +%F).tar.gz *.log ) && echo "Готово"
```

```bash
mkdir /tmp/backup 2>/dev/null && echo "Каталог создан"

# 2. Проверка с fallback
ping -c 1 8.8.8.8 > /dev/null && echo "Интернет есть" || echo "Нет интернета"

# 3. Фоновое выполнение
(sleep 30; echo "Готово" > /tmp/done.txt) &

# 4. Мониторинг
for i in {1..5}; do
    echo "Итерация $i: $(date +%T)"
    sleep 2
done

# 5. Комплексная задача
( cd /tmp && mkdir -p testdir && cd testdir && \
  touch file{1..5}.txt && ls -la ) | tee /tmp/result.txt
```
#### 10. Шпаргалка по горячим клавишам

Клавиши             | Действие
------------------- | -------------------------
Ctrl+C	 | Прервать текущую команду
Ctrl+D	 | Завершить ввод (EOF)
Ctrl+Z	 | Приостановить процесс
Ctrl+L	 | Очистить экран
Ctrl+A	 | В начало строки
Ctrl+E	 | В конец строки
Ctrl+U	 | Удалить до начала строки
Ctrl+K	 | Удалить до конца строки
Ctrl+W	 | Удалить слово назад
Ctrl+Y	 | Вставить удалённое
Ctrl+R	 | Поиск по истории
Tab | 	Автодополнение
Tab Tab	 | Показать варианты
↑ / ↓	 | История команд
