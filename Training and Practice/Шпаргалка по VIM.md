### Шпаргалка по VIM
Шпаргалка по vim
#### Запуск и выход

Команда             | Действие
------------------- | -------------------------
vim file	 | Открыть файл
vim +N file	 | Открыть файл на строке N
vim +/pattern file	 | Открыть файл на первом совпадении
vim -R file	 | Открыть только для чтения
vim file1 file2	 | Открыть несколько файлов
:e file	 | Открыть другой файл
:w	 | Сохранить
:w file	 | Сохранить как
:wq или ZZ	 | Сохранить и выйти
:q	 | Выйти (если нет изменений)
:q! или ZQ	 | Выйти без сохранения
:wq!	 | Сохранить и выйти (даже для read-only)
:x	 | Сохранить и выйти (только если есть изменения)

Советы
vimtutor — встроенный интерактивный учебник. Запустите vimtutor в терминале.
```bash
. — повторяет последнее действие. Очень мощная команда.

Ctrl+N / Ctrl+P — автодополнение в Insert mode.

:%s/\s\+$// — удалить пробелы в конце строк.

ggdG — удалить весь файл.

yyP — дублировать строку.

dw + p — поменять слова местами.

~/.vimrc — файл конфигурации vim.
```
Пример минимального ``~/.vimrc``:

```vim
set number
set relativenumber
set tabstop=4
set shiftwidth=4
set expandtab
set autoindent
set smartindent
set hlsearch
set incsearch
set ignorecase
set smartcase
set wrap
set mouse=a
set clipboard=unnamedplus
syntax on
```
